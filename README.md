# Парсер объявлений в Excel

Учебный прототип сбора объявлений с сайта и подготовки табличной выгрузки для дальнейшего анализа.

## Что сделано

- открытие страниц через Selenium;
- разбор HTML с BeautifulSoup;
- извлечение полей объявления;
- запись результата в Excel через openpyxl.

Код разделяет получение страницы, извлечение данных и сохранение результата, поэтому источник и набор полей можно заменить отдельно.

## Запуск

Установите зависимости из [requirements.txt](requirements.txt), настройте URL и параметры браузера, затем запустите Python-файл. Для Selenium потребуется совместимый браузер и драйвер. Перед массовым сбором проверьте правила сайта, частоту запросов и обработку блокировок.

## Ограничения

Это учебный прототип без планировщика, повторных попыток, устойчивых селекторов, тестов и хранилища. Структура HTML сайта может измениться; результаты сбора нужно проверять на пропуски и дубликаты.

**Инструменты:** Python, Selenium, BeautifulSoup, openpyxl.
