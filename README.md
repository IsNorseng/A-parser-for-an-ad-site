# Учебный сбор объявлений в Excel

Скрипт открывает заданную страницу через Selenium, извлекает заголовок, цену и описание с помощью BeautifulSoup и сохраняет их в Excel. [Исходный файл](Parser_verybad).

Для запуска нужны Python, Selenium, Beautiful Soup и openpyxl; `requirements.txt` в репозитории нет. URL и CSS-классы заданы в коде, файл сохраняется на рабочий стол Windows. Разметка сайта может измениться; перед использованием проверьте правила сайта и качество выгрузки.
